# go-stock Web 版使用指南

本项目已成功适配 Web 访问模式，支持通过浏览器远程使用 AI 股票分析功能。

## 🌟 Web 版新增特性

1.  **全平台访问**：支持通过 PC 浏览器或移动端浏览器访问（不再局限于 Wails 桌面客户端）。
2.  **安全鉴权**：集成 HTTP Basic Auth，保护您的 AI 接口和股票配置不被他人非法访问。
3.  **智能代码补全**：在关注股票时，系统会自动识别 A 股代码并补全市场前缀（例如输入 `601127` 自动识别为 `sh601127`）。
4.  **UI 自动优化**：针对 Web 环境自动移除了“退出程序”、“隐藏到托盘”等不适用的桌面端菜单项。
5.  **异步初始化**：优化了后端启动流程，确保庞大的词典数据加载不会阻塞 Web 服务的启动。

## 🛠️ 编译流程

在第一次运行或修改了前端/后端代码后，需要执行编译操作。

### 环境要求
*   **Go**: 1.20+
*   **Node.js**: 18+ (推荐 20+)
*   **NPM**: 随 Node.js 安装

### 一键编译
我们提供了一个自动化的编译脚本，它会处理前端打包和后端编译：

```bash
# 1. 赋予脚本执行权限（仅需一次）
chmod +x scripts/build-web.sh

# 2. 执行编译
./scripts/build-web.sh
```

该脚本会生成一个名为 `go-stock-web` 的可执行文件。

---

## 🚀 运行流程

### 快速启动
使用默认账号密码 (`admin / admin`) 启动服务：

```bash
# 1. 赋予执行权限
chmod +x start-web.sh

# 2. 启动
./start-web.sh
```

### 自定义配置启动
您可以通过环境变量自定义访问端口、账号和密码：

```bash
APP_USER=myname APP_PASSWORD=mypass PORT=9000 ./start-web.sh
```

## 📝 技术实现细节

*   **后端框架**: 基于 [Echo](https://echo.labstack.com/) 构建高性能 Web 服务器。
*   **前端适配**: 通过 `wails_adapter.js` 模拟 Wails 的 `window.go` 和 `window.runtime` 对象，使得前端 Vue 代码几乎无需改动。
*   **事件推送**: 使用 **SSE (Server-Sent Events)** 技术模拟 Wails 的事件总线，实现实时的行情和 AI 消息推送。
*   **静态资源**: 使用 Go 1.16+ 的 `//go:embed` 特性，将前端所有 HTML/JS/CSS 编译进二进制文件，实现单文件部署。

---

## ⚠️ 注意事项

1.  **浏览器缓存**: 如果您重新编译并更新了前端界面，但浏览器没有变化，请按 **`Ctrl + F5`** (Windows) 或 **`Cmd + Shift + R`** (Mac) 强制刷新。
2.  **网络建议**: Web 版默认运行在 `8080` 端口。如果您在服务器部署，请确保防火墙已放行该端口。
3.  **安全性**: 强烈建议在公网部署时设置复杂的 `APP_PASSWORD` 环境变量。
