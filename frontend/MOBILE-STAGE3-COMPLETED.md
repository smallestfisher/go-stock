## 🎨 组件详解

### MiniSparkline - 迷你走势线
```vue
<MiniSparkline :data="[100, 102, 101, 105, 108]" :width="80" :height="40" />
```
**特性：**
- ✅ Canvas 绘制，高性能
- ✅ 自动根据数据涨跌显示颜色（绿涨/红跌/灰平）
- ✅ 支持自定义宽高
- ✅ 支持填充渐变
- ✅ 适配 Retina 屏幕（DPR）
- ✅ 数据变化自动重绘

**绘制算法：**
- 自动计算数据范围（min/max）
- 坐标归一化到画布尺寸
- 先绘制填充区域，再绘制线条
- 线条平滑（lineJoin: round）

### StockCard - 股票卡片
```vue
<StockCard :stock="stockData" :show-sparkline="true" @click="handleClick" />
```
**特性：**
- ✅ 显示股票名称、代码
- ✅ 显示价格、涨跌幅、涨跌额
- ✅ 显示成交量、成交额（自动单位转换）
- ✅ 集成迷你走势线
- ✅ 可选是否显示走势线
- ✅ 点击反馈动画

**布局：**
```
┌───────────────────────────────────┐
│ 贵州茅台 600519    [走势线]  ¥1820.50│
│ 量: 12.5万        +2.34%          │
│ 额: 2.28亿        +41.60          │
└───────────────────────────────────┘
```

### VirtualList - 虚拟滚动列表
```vue
<VirtualList :items="stockList" :item-height="96">
  <template #default="{ item, index }">
    <StockCard :stock="item" />
  </template>
</VirtualList>
```
**特性：**
- ✅ 只渲染可视区域的项
- ✅ 支持大量数据（1000+项不卡顿）
- ✅ 自动计算可视区域
- ✅ 上下缓冲区（减少白屏）
- ✅ ResizeObserver 监听容器变化
- ✅ 数据变化自动重置滚动

**性能：**
- 假设 1000 只股票，每项高度 96px
- 传统列表：渲染 1000 个 DOM 节点
- 虚拟列表：只渲染 ~20 个 DOM 节点
- 性能提升：50 倍+

### StockDetailSheet - 股票详情抽屉
```vue
<StockDetailSheet
  v-model:show="visible"
  :stock="stockData"
```

## 🚀 使用方式

### 1. 访问自选列表页

**从首页：**
- 点击"自选概览卡片"的"查看全部 X 只 →"
- 或点击侧边抽屉的"我的自选"

**直接访问：**
- 浏览器访问 `http://localhost:5173/#/mobile/stock`

### 2. 查看股票详情

- 在自选列表中点击任意股票卡片
- 底部抽屉滑出，显示股票详情
- 可以切换标签页查看不同信息

### 3. 测试虚拟滚动

- 打开开发者工具 → Elements
- 滚动列表，观察 DOM 节点数量不变
- 始终只有 ~20 个股票卡片在 DOM 中

## 💡 技术亮点

### 1. 虚拟滚动优化
- 传统方式：1000只股票 = 1000个DOM节点 = 卡顿
- 虚拟滚动：1000只股票 = ~20个DOM节点 = 流畅

### 2. Canvas绘制走势线
- 不使用SVG，使用Canvas
- 性能更好，适合大量绘制
- 自动适配Retina屏幕

### 3. 组件可复用性
- StockCard 可在任何地方使用
- VirtualList 可用于任何长列表
- MiniSparkline 可用于任何走势展示

### 4. 用户体验优化
- 下拉刷新
- 点击反馈动画
- 空状态提示
- 流畅的抽屉动画
